# Task Tracker (JTRONIX Frontend Internship Assessment)

A React + Vite Task Tracker covering all three questions.

## Features
- 1.1 Add tasks via input + Add button (Enter works too); empty and whitespace-only tasks are blocked with an error message
- 1.2 Mark tasks Completed / Pending, delete tasks, live Total / Completed / Pending counts and a progress ring
- 1.3 All / Pending / Completed filter, localStorage persistence, responsive layout (desktop + mobile)
- Extras: empty states, "Clear completed", keyboard accessible, reduced-motion support

## Run locally
Requires Node.js 18+.

```bash
npm install
npm run dev      # open the URL shown (usually http://localhost:5173)
npm run build    # production build in /dist
```

## Project structure
- `src/App.jsx` – state, logic and components
- `src/index.css` – styling and responsive rules
